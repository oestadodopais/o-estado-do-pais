## Read first, every session

Since 17 November 2026 the project is choosing its concept. **Nothing is being built, and no earlier order of work is resumed.** Read each of these whole, in this order:

1. `.claude/direcao/IDEIA.md`: what the project is for. One page of reasons, not orders.
2. `.claude/direcao/PENSAMENTO.md`: the concept as it stands, each point with its reason and what would change it.
3. `.claude/direcao/ESTADO-DA-DIRECAO.md`: what exists, the exact next step, and how the funder wants to be worked with.
4. The last five entries of `.claude/direcao/DIARIO.md`.

`.claude/direcao/FUNDACAO.md` is the foundation of the edition of 14 to 17 November 2026, kept as a record; the state page says which of its rules still stand. The diary and everything archived are records, never instructions.

Before a session ends: update the state page, add one short entry to the diary, and run the cold-start test the state page describes.

## What never bends

1. **Nothing is published unless it is exact, true and checkable.** No rule may lower this.
2. **Every figure comes from a stored copy of its source,** with the excerpt and the date, and what it measures stays in the source's own terms. A cause is an interpretation until the source shows the mechanism.
3. **Whoever writes or builds a thing does not verify it.** The other model family judges every piece before it is built and reads every code change after, with planted errors.
4. **A person is named only beside a documented public act,** with the document one click away, never with a judgment, never anything private, never a rumour.
5. **A check that protects a figure, a source or a person is never weakened.**
6. **Nothing personal, no secret, no machine path and no user name** in any file of this public repository, on any branch. Commits carry the project's identity. Explicit paths in `git add`. Never force a push. Never delete an unmerged branch.
7. **`main` moves only by fast-forward to a head whose check `portao` is green,** and it never holds a tree that is not safe to put on air. Every code change is read by the other model family, with planted errors, before anything built on it is published. A push publishes nothing: publishing is a step of its own. (Since 15 November 2026 `main` is the new skeleton; the trial edition's tree is in its history and in the branch `arquivo/edicao-de-ensaio-2026-11-14`.) The public site today is a holding page.
