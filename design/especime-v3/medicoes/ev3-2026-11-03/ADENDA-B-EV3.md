# Adenda B ao mandato EV3: os tokens na sintaxe deste compositor (03.11.2026)

Acrescenta: frases

*A mesma sessão. Paraste bem outra vez: este compositor só aceita `⟦código:id⟧`, sem campo depois de `|`, e o token rende o valor da linha. Este lugar escreveu os tokens sem ler o compositor; desta vez a conversão é tua, porque és tu quem o lê.*

## §1 A conversão

Nas frases da adenda A (§2, pontos 1 a 4), cada token passa à sintaxe deste compositor. A regra: `⟦19:id|campo⟧` passa a `⟦código:id⟧`, com o código que este estudo usa para o seu livro, e o campo deixa de existir. Cada excerto é uma linha cujo valor é o excerto; cada data é uma linha cujo valor é a data, com o excerto que a diz; os votos e os dias são linhas cujo valor é o número. Se o valor de uma linha de data não renderizar na forma de data de cada edição, a linha leva o valor como o documento o escreve, e a edição inglesa usa uma linha irmã com a data na forma inglesa e o mesmo excerto (diz no relatório qual das duas formas usaste). Nenhuma palavra das frases muda, salvo a do §2.

- en «In this update, the association's latest published news item was still the one of ⟦código:ev3-ultima-noticia⟧, which does not announce the European Capital of Culture programme.»
