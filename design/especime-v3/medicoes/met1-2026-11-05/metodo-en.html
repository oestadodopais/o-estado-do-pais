From document to page

  1. An artificial intelligence model reads the news, source calendars and what parties publish, and identifies what has changed.

  2. A program downloads the source document, saves a copy with the request receipt and measures the number in the document itself.

  3. The number enters the ledger with its source, document, excerpt and date.

  4. Direction writes what changes and the sentences the reader will read, checked against the source.

  5. A model builds the change.

  6. Each build runs 62 automated checks across all pages: a digit without a ledger row, or with a different value, stops publication.

  7. A model from another family, which did not build the change, reads it against the documents, with five errors planted in its copies to measure whether it finds them.

  8. What the reading finds is corrected, and the correction is read again.

  9. Only work that has passed every check is published, and the published copy is checked again once it is live.

  10. The panel numbers are read again at the source, most recently on 02.11.2026; when the source changes a value, the number changes and the register shows what was there before.

The marks

  • source: opens the number’s receipt.
  • provisional data: the source says the value may still change.
  • calculated: the number was calculated from others, and the receipt shows the arithmetic.
  • to be confirmed at the source: a field of the receipt has not yet been confirmed in the document.
  • Amber: the value is outside the reference value published by the source. Cobalt: it is within it. A measure without a reference value carries no colour.
  • Study updated: the study has gained new documents. Study corrected: the text said something it should not have. The previous edition is always one tap away.

When a number changes

Each change is recorded in the corrections register, with the date, what was there and what replaced it.

These pages are written, checked and updated by artificial intelligence models; no person reviews each change before publication.
