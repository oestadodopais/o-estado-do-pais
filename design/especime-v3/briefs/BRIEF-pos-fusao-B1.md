## 2 · The form, under the constitution

- **Colour**: paper and ink, a 1px `--g3` rule under the banner; no colour; no dark variant (the document page does not load `public/js/tema.js`, so the reader's theme choice is not known there; the site is light for all by Emenda 12; the v2 rationale for a dark band «para se ler contra qualquer fundo» is replaced by the paper band with its ink rule, which reads against the dark documents; say so in the note and measure the contrast of the band's text on paper with `scripts/medir-contraste.mjs`'s formula, quoting the figures). **No literal typed**: `documentos.mjs` reads `src/styles/tokens.css` at build and extracts `--paper`, `--ink`, `--g1`, `--g3` from the `:root` block with a small parser that dies if a token is missing (the design-bundle generator has `paleta()` as a model). The banner's `<style>` declares them as custom properties scoped to `[data-oedp-faixa]`.
- **Type**: the banner's own `<style>` carries the `@font-face` rules for exactly the faces it uses (Spectral Regular, Spectral SC Regular; check the wordmark's weight in `site.css` and use that face), with the same same-origin paths as `tokens.css` (`/tipos/…`): read the declarations from `tokens.css` rather than retyping the paths, and `font-display: swap`. No system stack as the primary face (I11 closes); the fallback stacks are the ones `tokens.css` declares in `--f-prosa` and `--f-versal`. The gate's external-load check looks for `//` URLs; same-origin paths pass; say so.
- **Layout**: one row, flex, wrapping below 640px with the door back on its own line, the same `[data-oedp-*]` attribute selectors with the `oedp-` prefix so nothing collides with the document's own CSS; `box-sizing`, `all: revert`-style isolation only where the document's CSS leaks in (measure on the 04 PT document, which has the heaviest stylesheet, and on one EN document).
- **Accessibility**: the banner is a `<div role="banner">`? No: the document may have its own `<header>`; use `<div data-oedp-faixa lang="…">` with `lang` set per edition and an `aria-label` from the label string, so screen readers name it once.
