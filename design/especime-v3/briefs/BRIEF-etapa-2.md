## 1. Rules that bind every line you write

The rules of `BRIEF-etapa-1.md` §1 apply word for word (nothing outward; no governed byte; no new gate, only extensions proven on planted defects you revert; no invented numbers in documents; PT and EN in the same commit; `npm run build` green at every commit; the stage note at the checkpoint; read the scripts). Plus, for this stage:

- **Runtime code selects prevalidated strings and never formats a figure** (the director's answer 3). Everything the page can show in any state is in the HTML the server built, as text the gate sweeps; the script only toggles `hidden`, `open`, `aria-pressed`, `aria-current` and `textContent` of two marked slots (the chosen concelho's name and its district, both copied from the CAOP island already in the page). No `innerHTML`, no template literals producing visible text, no arithmetic producing a displayed digit.
- **Relocation before movement**: every sentence or value that appears on the home came from a route named in `RELOCACOES.md` with the occurrence count you then confirm, or is new copy listed under «Texto novo» with its EN. A sentence from the board that is neither is not written.
- **Shared files are builder A's.** If you need a change in `tokens.css`, `site.css`, `Base.astro`, `Masthead.astro`, `SiteFooter.astro`, `Claim.astro`, `Provenance.astro`, `Frase.astro` or `PortaDeCorreccoes.astro`, you do not edit them: write the exact change you need in `../notas/stage-2.md` under «Pedidos ao dono da folha» and continue; the seat routes it. Your own styles go in the scoped `<style>` of your components and in `src/styles/inicio.css`, imported by `HomeView.astro` only.
- **Editorial calls are the director's.** The wording of any public sentence, the form of a state or an empty state, which measures the home carries and in what order, what the navigation contains, whether a value shows as provisional: not yours. Where the board's copy is new, you write it into `strings.mjs` in both languages as the best version you can, list it under «Texto novo», and move on; you never invent a value, a date or a count.
