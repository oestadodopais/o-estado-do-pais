## 2. The director's four answers, applied as rules

1. **Content invariance is an advisor.** `scripts/medir-invariancia.mjs` (new, outside `npm run build`, beside `medir-defeitos.mjs`) prints and never fails: a text dump per route per edition (text nodes, `script`/`style` removed, the same `textoDe` discipline as the gate) compared between the base build and the branch build, with the differences listed per route; and, for the stateful home, a **DOM dump of a state matrix** rendered in headless Chromium (Playwright as a devDependency, used only by scripts outside the build). Anything that must be enforced becomes an extension of `gate:html`, `ledger:check` or `check:dados`, each proven on a planted defect and listed in the stage note. If a stage concludes it needs a check that must pass before merge and no existing gate can carry it, it stops and asks with the uncovered defect and the proposed contract. No new gate.
2. **Relocation register** (`design/especime-v3/RELOCACOES.md`, started in stage 0, §10). Text and numbers move only by an entry written before the move: source route, destination route, component, scope, language, occurrence count (source → destination), claim id or proof key. The visible scope label and the value move as one unit. There is no «it existed somewhere on the old site» exception. A relocation not in the register is a defect the cross-family read is told to look for.
3. **Runtime code selects prevalidated strings and never formats a figure.** The home declares a closed URL state schema (§13). Every query value resolves through closed route data (the five regions and the 308 CAOP slugs as built lists), unknown or invalid values fall back to the server-rendered default without error text, nothing goes into `innerHTML`, and the default page (País · Relance) is correct with JavaScript off. The invariance advisor dumps the rendered DOM for the state matrix, not only the source HTML.
4. **Governed changes land in the same commit as their decision entry**, with `Afecta:` and the digest, per §1.38. No governed byte changes before the director approves the exact sentence. The two `IDENTIDADE.md` changes (§1 type, §2 colour) get their own entry before the first stage that depends on them (stage 1, first substage).
