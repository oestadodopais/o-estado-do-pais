`pdf_cell` only requires each header line to occur somewhere on the page, the unit string to occur anywhere on the page and the period to occur anywhere in the header text; the column index, the occurrence of a repeated label and the `stage` come from the hand-written selector and are never compared with the layout. Every OE header prints both years and the CGE header prints "2025" over both "Orçamento Corrigido" and "Execução", so a selector on the neighbouring column, carrying that column's value, passes `verify()` and the test; for the four calendar rows the date anchor is the same fixed string, 08.10.2026, and `date_pattern` is unset, so `period` is never compared with the quote. The plants do not probe this: the period plant uses an absent year (1900), the column plant uses 999, and the "derivação, conta refeita" plant sets an `expected_value` that none of the 100 real derived selectors carries, so that branch never runs on the data.
