## Blocking

1. **The supplied robots change is the opposite of the report and makes every hosted document fail its own gate.** The generator emits `content="index, follow"` (`documentos.mjs:584`) and injects it unconditionally (`documentos.mjs:622-630`), while the gate requires exactly `noindex, follow` (`diff-sitio.patch:1014-1033`). With no pre-existing robots meta, content validation fails; with one, the count fails. The claimed green builds are therefore impossible for the supplied postimage (`relatorio-construtor.md:312-324`). The patch header declares postimage `47ca8a22`, but its body and copied file contain the wrong value (`diff-sitio.patch:1255,1357`; `documentos.mjs:584`); changing only `index` to `noindex` produces that declared postimage. The package is not a faithful copy of the named diff.

2. **The motor workflow does not install the lock.** Its comments and cache name `requirements.lock.txt`, but the command remains `pip install -r requirements.txt` (`portao-motor.yml:92,103-112`; `diff-motor.patch:34-44`). Those requirements contain floating ranges (`requirements.txt:4-44`), so the reported CI run cannot prove that the lock resolves on Python 3.12/Linux (`relatorio-construtor.md:248-250,323-326`). The declared postimage is `ae400ea`, but the supplied body/copy do not match it (`diff-motor.patch:2,43-44`; `portao-motor.yml:108-112`); changing only the install target to the lock produces the declared postimage.

3. **The byte-preservation rule is neither absolute nor independently proved.** Sources are decoded as UTF-8 and transformed as JavaScript strings (`documentos.mjs:603-630,677-678`), so legacy encodings or invalid UTF-8 can alter bytes throughout the document. The first textual `<html>`, `<head>` and `<body>` matches are used without parsing context (`documentos.mjs:607,622,646-655`), so tag-like text in comments or scripts can select the wrong insertion point. The gate recalculates expected output through the same transformer, explicitly changing both sides of its equality (`diff-sitio.patch:977-981`), and therefore mirrors such corruption rather than proving the original suffix.

   Existing structures are handled as follows: no `<head>` is a hard failure (`documentos.mjs:622-627`); no `<body>` is accepted if `</head>` exists (`documentos.mjs:646-660`); an existing robots meta is duplicated before the gate rejects it (`documentos.mjs:629-630`; `diff-sitio.patch:1019-1033`); an existing empty or wrong `lang` is preserved by the injector and later rejected (`documentos.mjs:614-619`; `diff-sitio.patch:997-1011`). Injecting before an author’s charset declaration can also change encoding detection (`documentos.mjs:622-630`). The banner adds a new first body child and unscoped `@font-face` rules, so author CSS/scripts or font-family definitions can affect each other (`documentos.mjs:443-445,560-574,646-650`).

## Major

4. **The document and language counts are not established.** No `studies-src` files or built documents are supplied (`LEIA-ME.md:3`), and the module accepts any discovered inventory, including one redirected by `OEDP_STUDIES_DIR` (`documentos.mjs:94-121,133-181`). The report says eight documents lacked `lang` (`relatorio-construtor.md:44-52`) but its standalone closing line says 16 of 16 (`relatorio-construtor.md:337`); the embedded report says 8 of 16 (`diff-sitio.patch:361`). The module itself first says all 16 lacked language, then says eight already had it (`documentos.mjs:18-27`), and its CSS notes refer to measurements over only 15 documents (`documentos.mjs:422-448`). The package cannot identify which eight receive `lang`; the code merely modifies the first matched `<html>` lacking a textual `lang=` (`documentos.mjs:607-619`). The “no existing robots meta” evidence only searched the exact double-quoted spelling `name="robots"`, missing single quotes, whitespace around `=`, and equivalent syntax (`relatorio-construtor.md:46-50`).

5. **The three new gate rules are weaker than reported.** Language is checked as non-empty with a matching primary subtag (`diff-sitio.patch:997-1011`). Robots are counted anywhere in the document, with no test that the meta is inside `<head>` (`diff-sitio.patch:1019-1033`). The AI label is not compared character-for-character: entities are decoded and whitespace is normalised before comparison (`diff-sitio.patch:1051-1058`). These checks can therefore pass a body-level robots meta and whitespace/entity variants contrary to the stated contract.

6. **Nineteen identifiers/declarations were removed, not eighteen.** The diff removes 2 in the gate (`diff-sitio.patch:878,1119`), 3 in `check-lingua` (`diff-sitio.patch:574-585`), 6 component imports (`diff-sitio.patch:1224,1506-1508,1523-1525,1539`), and 8 other view bindings/declarations (`diff-sitio.patch:1473,1485-1494,1511,1527,1543-1544,1556,1568-1569`). The likely undercount is the `HomeView` cascade: `estadoDaVerificacao` initially appeared used only by the dead `verificacao`, so the occurrence counter would first report the latter and expose the former only after removal (`check-mortos.mjs:175-190`).

7. **The dead-identifier scan can pass with dead code present.** Any second occurrence in a comment, string, fixture text, or another declaration counts as use by design (`check-mortos.mjs:37-45,167-188`). It only recognises regex-shaped static imports and unindented single-name `const` declarations; `let`, `var`, functions, classes, destructuring, indented declarations, TypeScript, and other extensions are outside its coverage (`check-mortos.mjs:23-34,76-92,141-162`). Its proof checks one synthetic import in a temporary file and does not test those blind spots (`check-mortos.mjs:193-226`). No explicit environment bypass is shown; omitting `--prova` skips only the self-test, while `verify` forces it (`check-mortos.mjs:230-235`; `package.json:33-34`).

8. **The allowlist orphan rule can be satisfied by an exemption that exempts nothing.** Context usage is incremented whenever a declared `data-nonledger` value is rendered, without establishing that its element contains a numeric token requiring exemption (`diff-sitio.patch:1123-1129,1154-1160`). An inert attribute on number-free markup therefore makes the counter non-zero. Duplicate context or token declarations also collapse into `Set`/`Map` keys and are not detected independently (`diff-sitio.patch:894-938,1167-1201`). Token and pattern counters are stronger because they increment only after a token match (`diff-sitio.patch:945-964`). No new environment-variable or command-line bypass is shown in this rule.

9. **The dirty-tree alarm does not measure how long outputs have stayed uncommitted.** It measures the timestamp of the last commit that touched each currently dirty file (`diff-motor.patch:147-161`). A file last committed months ago and changed today is immediately reported as months overdue; the proof deliberately codifies that false model by modifying today a file whose base commit is eight days old (`diff-motor.patch:224-246`). The real check runs only under `--check-heartbeat` or `--check-por-commitar`, not during a normal refresh, and the asserted launchd invocation is not supplied (`diff-motor.patch:184-195,274-283`; `relatorio-construtor.md:302-306`). Passing `--prova-por-commitar` alongside a real-check flag bypasses the real tree because it has dispatch precedence (`diff-motor.patch:277-283`). The inherited Git environment/index also permits an alternate `GIT_INDEX_FILE`, ignored untracked output, or `assume-unchanged`/`skip-worktree` state to make `git status` report clean (`diff-motor.patch:127-150`).

10. **The lock is a version snapshot, not a fully reproducible lock.** It contains exactly 40 `==` pins and no hashes (`requirements.lock.txt:34-73`). Its nine direct versions satisfy the nine declared ranges (`requirements.txt:4-44`; `requirements.lock.txt:37,50,52,59,62,64,66,69,72`), but the package contains no resolver report proving the other 31 are every transitive dependency on both target platforms. It was reportedly frozen only on Python 3.14/macOS (`requirements.lock.txt:13-29`), and the workflow floats pip itself before installation (`portao-motor.yml:108-112`). Artifact identity, installer version, and platform-conditional dependency resolution are therefore unlocked.

11. **The four panel outputs are unsupported assertions.** The package supplies neither the four JSON files nor `refresh.log`; it supplies only a stat naming four changed files (`diff-motor.stat:2-6`) and builder-authored descriptions and hashes that cannot be checked (`relatorio-construtor.md:252-270`). That is insufficient to establish that the bytes are the panel’s own outputs, reconcile them with the two runs, exclude hand edits, or prove commit `63d3a34` contains those exact bytes (`relatorio-construtor.md:254-268,328`).

12. **The site dependency lock is unreviewable.** `package-lock.json` is deliberately omitted even though it changes by 631 lines (`LEIA-ME.md:3`; `diff-sitio-lock.stat:1-2`). The manifest proves the two requested direct versions, but not the resolved dependency tree or the claim that no unintended package changes occurred (`package.json:36-45`; `relatorio-construtor.md:95-108`).
