## 3 · The studies: one door, attached to their place [P]

A study is a page with: the title; the project's reading (the opening: «Em resumo», «O que este projeto conclui», «O que podia funcionar melhor»); the text of the study; at the end, one line: «Documento original (PDF)» for the edition as published, and the date. There is no "Edições" box and no second door. The English edition is reached by the site's language switch, as every other page. The studies list shows every study newest first, with its title, its place and theme, its date and the first paragraph of its reading. The front page and each place page show their studies the same way. A study's numbers keep their receipts exactly as today.

**Portugal · Lugares · Temas · Estudos · Sobre.** Portugal abre a primeira página. Lugares abre a geografia. Temas abre as oito portas do §2. Estudos abre a lista. Os domínios e as áreas de governo saem dele.

## 5 · The three rules that the checks enforce [P]

1. **Nothing explains itself.** On a reader page every sentence is content: a number, a name, a fact, a reading. Section labels come from a closed list («Temas», «Estudos sobre este lugar», «O que mudou», «Fonte», «Verificado a»). A sentence that describes the page, the project, the method or the source belongs on Sobre, Método or the receipt, once. The build fails on any other sentence.
2. **One door per thing.** One link to a study, one to a place, one to a theme. No box that lists doors. No link whose text explains what it opens.
3. **The vocabulary is the site's, in European Portuguese, and use is checked in context.** Not a list of banned words: a list of things and the word for each, with where the word belongs (§6). "Casa" is housing; the project is «O Estado do País» or «este projeto». "Sítio" is a place; a web page is «página» and the whole is «o projeto». The check flags a word used outside its place, not the word.

## 6 · The vocabulary [P, for [o diretor] to correct]

| the thing | the word on the site | where it belongs, and where not |
|---|---|---|
| the project | O Estado do País; este projeto | never «a casa», never «o sítio», never «o site» |
| a page of the site | página | never «sítio» |
| the whole site, when it must be named | o projeto; este endereço only in technical notes | never «o sítio» |
| a subject | tema | never «domínio» or «área de governo» on a reader page; «domínio» in the charter and the code |
| a place | lugar; concelho, distrito, ilha, região, país | never «unidade» on a reader page |
| a measured quantity | medida | «indicador» only where a source calls it so, in the receipt |
| the value the measure is compared with | valor de referência | never «limiar» |
| the source | fonte | once per number, in the receipt link |
| the receipt page of a number | Fonte e verificação (the page's title) | «recibo» and «livro-razão» in the code and the method, not on the page |
| the project's text about a study or a place | leitura | «Em resumo», «O que este projeto conclui», «O que podia funcionar melhor» |
| the action of opening a study | Ler | never «Ler no sítio»; the original edition is «Documento original» |
| the list of coming releases | Agenda | |
| what is new | O que mudou | never «novidades», «atualizações» |
| verified on | verificado a | the date only |
| published on | publicado a | the date only |
| a study | estudo | never «trabalho», «peça», «documento» for the study itself; «documento» is the source's document |
| the housing theme | habitação | «casa» is a house and nothing else |
| home (the front page) | Portugal, or Início in the footer | never «Home» |

English words that shall not be translated one to one: site (→ projeto/página), home (→ início), dashboard (→ painel, internal only), card (→ cartão, internal only), receipt (→ the page «Fonte e verificação»), threshold (→ valor de referência), domain (→ tema), edition (→ edição, internal only), snapshot (→ a data da leitura).
